**🚗 Locadora de Veículos** — sistema web para gestão de locadoras, com API em **.NET 8** e front-end em **Angular 20**.
Multiempresa (cada locadora vê só os próprios dados), acesso por perfil (administrador e funcionário), autenticação com **JWT** e arquitetura em camadas com **CQRS**.
